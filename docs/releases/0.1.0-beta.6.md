## 面经题包交付

- public ARM64 APK 仍使用空 SQLite 种子，但会携带 descriptor 精确绑定的 r1 面经题包 Asset。
- 首次可用时，Android 只会在原生确认框显示题包预览；只有点击“确认安装”才会写入本地数据库。取消、校验失败或进程死亡后，同一哈希不会再次自动提示；“设置 → 面经题包 → 安装内置题包”始终可手动重新打开预览。
- 同一份 `ai-bagu-2026-autumn-interviews-r1.bagu-pack` 仍是 Release 独立附件，供桌面端和 Android 手动导入。更新清单与 Beta Pages 只描述 APK，不包含题包下载或自动更新字段。
- Release 恰有七个外部附件：public ARM64 APK、独立题包、`SHA256SUMS`、证书指纹、`INSTALL.md`、`RELEASE_NOTES.md` 和 `update.json`。Stable 清单保持 `release:null`。
