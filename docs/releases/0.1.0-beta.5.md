# 八股助手 0.1.0-beta.5

面经题包与专题模拟版本。本文件描述已完成本地验证、等待公开发布的内容，不表示 Release 已经公开。

## 主要变化

- 增加本地 `.bagu-pack` 检查、明确确认安装、增量升级和日常复习开关。
- 练习页增加“面经模拟”，支持按专题整套或章节顺序练习。
- `prepare` 准备项只记录已准备或跳过，不调用模型，也不修改间隔调度。
- `.bagu-backup` v3 保存题包结构、启用偏好和稳定 ID 进度；继续兼容 v1/v2。

## 正式题包附件

- `2026 秋招面经库` revision 1 是独立 Release 附件，APK 不内置题包，也不会自动下载或更新题包。
- 题包答案由 AI 生成，并由维护者接受为已复核参考答案；它们不是原帖作者或面试公司的标准答案。
- 题包内容仅供个人学习及在八股助手中使用，内容权利保留；应用源码的 MIT 许可证不适用于题包内容。

## 安全与数据

- public APK 仍使用空题库；题包必须下载后在题库管理中检查预览并明确确认导入。
- 更新清单仍只描述 APK，不包含题包下载地址或自动更新字段。
- 有进行中的练习时不能安装或升级题包；已有学习进度按稳定 ID 保留。
