# 八股助手 0.1.0-beta.4

这是尚未公开发布的 beta.4 候选说明。公开发布、远端更新清单和 Git Tag 需要另行确认。

## 主要变化

- 修复 Android 15 及以上系统中安装确认页可能被系统静默拦截的问题。
- 安装更新改用受保护的 `PackageInstaller.Session` 回调，并新增脱敏确认阶段诊断。
- 主动操作失败统一使用可访问弹窗，明确显示错误信息、解决办法和可用操作。
- 更新可用提示采用紧凑的 Compact Editorial 卡片，先查看详情，再决定是否下载。

## 安全与数据

- 不自动结束练习、不自动重试写操作，也不自动下载或安装更新。
- 安装成功仍以后续启动核对实际 versionCode 为准。
- public 包首次安装为空题库；同包名、同签名覆盖升级不会主动清除应用私有数据。
